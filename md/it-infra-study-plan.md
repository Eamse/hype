# 영원무역 IT(기획) 신입 지원 — IT 인프라 학습 계획

## 채용 공고 요건

**필수사항**
- IT 인프라(서버, 네트워크, 보안, 백업, 스토리지) 관련 이해도 보유자
- 중급 이상의 MS Office(파워포인트, 워드, 엑셀) 사용 가능자
- ESPT 601점 이상
- 해외 출장 미결격자

**우대사항**
- Python, HTML, CSS, JavaScript 기본 이해 가능자
- SQL 작성 가능자(SELECT, JOIN 등)
- 제조업 경험자
- 영어 회화 능력 우수자

## 우대사항은 이미 거의 충족

이 포지션은 직접 서버를 만지는 엔지니어가 아니라 **"IT 기획/지원"** 역할이라, 깊게 구현할 줄 알아야 하는 게 아니라 **개념을 이해하고 협업사/개발팀이랑 커뮤니케이션할 수 있는 수준**이면 충분하다.

- **SQL(SELECT/JOIN)**: hypewedding.kr 프로젝트에서 Prisma로 관계 조인, 재고 계산 등 실제로 짜봤음 → 확실히 통과
- **Python/HTML/CSS/JS 기본 이해**: 이 프로젝트가 TS/React/CSS 실전이라 개념적으로 충분히 커버됨
- 면접에서 "이 프로젝트 만들면서 이런 거 다뤄봤다"고 얘기할 거리가 이미 있음

## 필수사항(IT 인프라 이해도) — 개념/용어 위주로 준비

"구현 경험"이 아니라 "개념+용어" 수준이면 충분하다.

- **서버**: 온프레미스 vs 클라우드 차이, 가상화(VM)/컨테이너(Docker) 개념, 서버 스펙(CPU/RAM/디스크) 보는 법
- **네트워크**: IP/서브넷/방화벽/VPN이 뭔지, 사내망-외부망 구분, 재택 접속용 VPN 원리
- **보안**: 계정 권한 관리(최소 권한 원칙), 백신/EDR, 피싱 대응, 랜섬웨어 사례(뉴스 수준)
- **백업**: 백업 주기(일간/주간), 풀백업 vs 증분백업 차이, RTO/RPO(복구 목표 시간/시점) 용어
- **스토리지**: NAS/SAN 차이, 클라우드 스토리지(S3 등) 개념, 용량 산정 기본 감각

정보처리기사/네트워크관리사 필기 요약 자료나 유튜브 개념 강의 몇 개로 용어랑 큰 그림만 잡아도 충분함. 면접에서 "이해도 보유"를 증명하는 건 깊은 구현 지식보다 "이게 왜 필요한지, 뭐랑 뭐가 다른지"를 설명할 수 있느냐임.

## 실전 경험 포인트

hypewedding.kr 작업하면서 실제로:
- nginx 리버스 프록시 설정 (도메인 3개 사이트 분리)
- DNS/SSL(certbot) 개념 확인
- SSH 보안 강화 (비밀번호 로그인 차단, 키 기반 인증만 허용)
- DB 백업(`pg_dump`) 실행

→ "신입인데 실제 도메인 인프라 세팅해봤다"는 자소서/면접에서 얘기할 수 있는 꽤 좋은 재료.

## 추천 학습 순서

**네트워크 → 서버 → 보안 → 백업/스토리지** 순으로 용어부터 정리.

이론서보다는 실제로 서버 만지면서 "이게 왜 안 되지"를 겪는 게 훨씬 빨리 는다.
