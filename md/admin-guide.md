# Hype Wedding 어드민 사용 가이드

> 코딩 몰라도 괜찮아요. 순서대로 따라하시면 됩니다.

---

## 어드민 접속 방법

웹사이트 주소 뒤에 `/admin` 을 붙여서 접속합니다.
예) `https://hypepig.com/admin`

---

## 전체 흐름 한눈에 보기

```
① 작가 등록   →   ② 상품 등록 (작가 연결)   →   ③ 상품에 작가 추가/제거
  (Directors 탭)     (Photographers 탭)              (상품 카드 내 Director 버튼)
```

**순서가 중요한 이유:**
상품을 등록할 때 작가를 선택해야 하는데, 작가가 먼저 등록되어 있어야 목록에 뜹니다.
**작가부터 등록하세요.**

---

## ① 작가 등록

**어디서:** 왼쪽 메뉴 → `Directors` 탭

작가를 등록하면 나중에 상품에 연결할 수 있습니다.

**등록할 정보:**

| 항목 | 예시 | 필수 여부 |
|------|------|----------|
| 번호 | #1-1 | 필수 |
| 이름 | Jeju and You (Main Director) | 필수 |
| 인스타그램 | @jejuandyou_snap | 선택 |
| 프로필 이미지 | 파일 첨부 | 선택 |

**순서:**
1. `Directors` 탭 클릭
2. 상단 등록 폼에 정보 입력
3. 프로필 이미지는 `파일 첨부` 버튼으로 업로드
4. `등록` 버튼 클릭

수정하려면: 작가 옆 `수정` 버튼 클릭
삭제하려면: 작가 옆 `삭제` 버튼 클릭

---

## ② 상품 등록 (작가 연결 포함)

**어디서:** 왼쪽 메뉴 → `Photographers · Jeju` 또는 `Photographers · Seoul` 탭

① 에서 등록한 작가를 여기서 상품에 연결합니다.

**등록할 정보:**

| 항목 | 예시 | 필수 여부 |
|------|------|----------|
| 제목 | Jeju and You | 필수 |
| 브랜드 | Hype Wedding | 필수 |
| 가격 | 2690000 | 필수 |
| 설명 | 제주 대표 웨딩 스냅... | 선택 |
| 썸네일 이미지 | 파일 첨부 | 선택 |
| Directors | 작가 선택 (체크박스) | 선택 |

**순서:**
1. 해당 탭에서 `+ Add Product` 버튼 클릭
2. 정보 입력
3. 하단 Directors 항목에서 이 상품에 참여하는 작가 체크
4. `Save` 버튼 클릭

> 저장하면 웹사이트 웨딩 페이지에 썸네일로 바로 표시됩니다.

---

## ③ 상품에 작가 추가/제거 (등록 후)

상품 등록 후에도 작가를 추가하거나 제거할 수 있습니다.

**순서:**
1. 상품 카드에서 `Director ▼` 버튼 클릭
2. 드롭다운에서 추가할 작가 선택 후 `연결` 클릭
3. 제거하려면 연결된 작가 옆 `해제` 버튼 클릭

---

## 각 탭 기능 설명

| 탭 이름 | 하는 일 |
|---------|---------|
| Dashboard | 전체 현황 요약 |
| Hero Image | 메인 페이지 슬라이드 이미지 관리 |
| Directors | 사진작가 등록 / 수정 / 삭제 |
| Photographers · Jeju | 제주 웨딩 상품 관리 |
| Photographers · Seoul | 서울 웨딩 상품 관리 |
| Casual · Jeju | 제주 캐주얼 촬영 상품 관리 |
| Casual · Seoul | 서울 캐주얼 촬영 상품 관리 |
| Members | 가입 회원 목록 확인 |
| Account Setting | 어드민 계정 추가 / 관리 (마스터 전용) |
| My Account | 내 비밀번호 변경 |

## 자주 묻는 질문

**Q. 작가를 먼저 등록하지 않으면 어떻게 되나요?**
A. 상품 등록 시 작가 선택 목록이 비어있게 됩니다. Directors 탭에서 먼저 등록해주세요.

**Q. 상품 썸네일 이미지는 어떻게 바꾸나요?**
A. 상품 카드에서 `▼펼치기` 버튼을 클릭하면 이미지가 보입니다. 이미지를 클릭하면 바로 변경할 수 있습니다.

**Q. 상품을 삭제하면 복구가 되나요?**
A. 삭제한 상품은 복구되지 않습니다. 신중하게 삭제해주세요.

**Q. 웹사이트에 바로 반영되나요?**
A. 네, 저장 즉시 웹사이트에 반영됩니다.

**Q. 비밀번호를 잊어버렸어요.**
A. 마스터 관리자에게 문의해주세요. Account Setting 탭에서 초기화할 수 있습니다.
